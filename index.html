Core Features

A modular AI application designed to combine language models, external tools, persistent state, and knowledge retrieval.

🧠

Agentic Workflow

LangGraph coordinates the chatbot, conditional routing, tool execution, and response generation.

📄

PDF Knowledge Base

Upload PDF documents, extract their text, split it into chunks, and index the content for semantic retrieval.

🔎

RAG and Semantic Search

Pinecone retrieves relevant document passages to provide context for document-based answers.

🛠️

Tool Integration

Registered tools support calculations, internet search, weather queries, and knowledge base retrieval.

💾

Conversation Persistence

PostgreSQL-backed LangGraph checkpointing preserves conversation state for later restoration.

⚡

Streaming Chat Interface

Streamlit displays conversation history, tool activity, response updates, and conversation management controls.

How It Works

From user input to an AI-generated response.

STEP 01

Submit a Question

The user sends a question through the Streamlit chat interface.

STEP 02

Process with the Agent

FastAPI passes the request to LangGraph, which invokes the chatbot model.

STEP 03

Execute Tools if Needed

The graph routes tool calls to the appropriate registered tool and processes the returned results.

STEP 04

Return the Response

The response is delivered to the frontend, while graph checkpoints preserve state.
